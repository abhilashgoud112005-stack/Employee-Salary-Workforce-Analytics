# Employee Salary & Workforce Analytics

## 📌 Project Overview
A Python-based data analytics project that explores employee salaries and workforce information using data cleaning, statistical analysis, and visualization.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📂 Project Features
- Data cleaning and preprocessing
- Missing value handling and duplicate removal
- Salary and employee statistics
- Department-wise salary analysis
- Employee performance and job satisfaction analysis
- Gender, city, and work mode distribution
- Correlation analysis
- Top 10 highest-paid employees
- 10 data visualizations

## 📊 Visualizations
- Gender Distribution
- Department-wise Employee Count
- Salary Distribution
- Salary vs Experience
- Average Salary by Department
- Job Satisfaction Distribution
- Performance Score Distribution
- Work Mode Distribution
- Correlation Heatmap
- Top 10 Highest Salaries

## 📁 Files
- `salary_analytics.py` — Main Python program
- `employee_salary_workforce_analytics.csv` — Original dataset
- `cleaned_employee_salary_workforce_analytics.csv` — Cleaned dataset
- PNG files — Generated charts and visualizations

## ⚙️ Installation

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

## ▶️ How to Run

1. Clone or download this repository.
2. Ensure the CSV dataset is in the path expected by the Python script.
3. Run the program:

```bash
python salary_analytics.py
```

The program performs data analysis and generates visualizations.

## 🎯 Objective
To analyze employee salary and workforce data and identify patterns in compensation, department distribution, performance, experience, and job satisfaction.
